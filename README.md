## 搬瓦工是什么类型的 VPS

搬瓦工的正式品牌名是 BandwagonHost，运营方为 IT7 Networks。它提供的是 **自主管理型 KVM VPS**，用户获得 root 权限，系统安装、软件配置、安全更新、备份策略和故障排查基本都需要自己负责。

官方使用 KiwiVM 作为控制面板，常见功能包括：

- 开关机和强制重启
- 重装操作系统
- 紧急控制台
- PTR / rDNS 设置
- 机房迁移
- 快照
- 自动备份
- 流量统计
- API 管理

这类服务和带运维团队的托管云主机不是一回事。搬瓦工提供基础设施和控制面板，但不会替你安装 WordPress、配置 Nginx，也不会因为网站程序报错就自动处理。官方页面也明确将服务定义为 self-managed，也就是自主管理型服务。

因此，搬瓦工更适合以下用户：

- 会使用 SSH 和 Linux 命令行的人
- 想自己部署网站、代理服务、开发环境或测试项目的人
- 需要 root 权限和独立公网 IPv4 的用户
- 想在多个机房之间迁移 VPS 的用户
- 对中国大陆访问海外服务器的网络质量比较敏感的人

如果你只想上传文件、绑定域名，然后等待客服帮你处理服务器问题，搬瓦工可能不是最省心的选项。

## 搬瓦工评测结论：优点和限制都很明确

### 主要优点

**第一，控制面板功能比较完整。**

KiwiVM 并不是漂亮的 SaaS 控制台，但常用的 VPS 管理功能基本齐全。重装系统、迁移机房、修改 PTR、查看流量和创建快照都可以直接完成，不需要每次提交工单。

官网标准 VPS 从 1GB 内存的 20G KVM 开始，一直到 24GB 内存的 480G KVM。除此之外，还有 CN2 GIA、ECOMMERCE SLA、香港、日本、东京、大阪、新加坡和迪拜等专项方案。个人博客和中小型项目可以从低配开始，企业级业务也有更高规格的方案。

CN2 GIA 方案通常会标明中国电信 CN2 GIA、联通或移动方向的优化线路。需要注意的是，“支持 CN2 GIA”不等于所有运营商、所有地区、所有时间段都能保持同样延迟。跨境网络会受到运营商、出口拥塞、机房负载和目的地网络的影响，不能把线路名称理解成永久稳定的速度保证。

官网公开页面写明普通 VPS 提供 30 天退款政策，并展示 99.9% uptime guarantee；购物车中的部分促销 VPS 则标注 99.95% uptime guarantee。不同产品线的条款可能不同，购买前应以具体订单页和服务条款为准。

### 主要限制

**自主管理意味着你需要自己承担维护成本。**

系统更新、SSH 安全、数据库备份、网站恢复、日志分析和防火墙配置都不是购买后自动完成的。配置不当导致服务中断，不能简单归咎于套餐性能。

**网络线路不是唯一变量。**

同一个机房，不同运营商的表现可能不同。电信用户关心 CN2 GIA，联通用户可能更关注联通回程，移动用户则需要单独测试。购买前查看路由和延迟很有价值，但测试结果也不代表未来每一天的表现。

**高规格专项套餐价格增长很快。**

普通 KVM 从低价入门方案到高内存方案，价格变化还算容易理解；但东京、香港、新加坡等 CN2 GIA 线路的高配版本，月付价格可能明显高于普通 KVM。为了一个个人博客买大规格线路，通常没有必要。

预算有限时，可以从 40G 或 80G KVM 开始。WordPress 如果安装大量插件、开启对象缓存并运行数据库，2GB RAM 往往比 1GB 更稳妥。

### 独立站和小型电商

独立站需要同时考虑 CPU、数据库、磁盘和网络。80G KVM 可以承载小规模项目，但如果订单、图片、后台操作和数据库负载增长，ECOMMERCE SLA 的 NVMe、ECC 和更高链路会更有吸引力。

### 开发和测试环境

搬瓦工的 root 权限、快照、重装和迁移功能适合开发者。20G KVM 可以作为低成本实验环境，80G 或 160G 更适合同时运行数据库、容器和多个服务。

开发环境应设置自动备份，并避免把唯一一份代码、数据库或密钥放在 VPS 上。快照不是完整的灾难恢复方案，尤其不能替代异地备份。

### 跨境 API 和远程服务

如果应用用户分布在中国大陆、东南亚和美国，应该比较多个机房，而不是只看服务器本身的 CPU 配置。CN2 GIA ECOMMERCE、东京、大阪和新加坡方案提供了更多网络位置选择。

这类项目建议在购买后进行一段时间的实际监测，包括：

- 三网延迟
- 丢包率
- 晚高峰可用性
- 到主要 API 目标的连接速度
- DNS 解析时间
- TCP 和 TLS 建连时间

## 搬瓦工购买前要注意的几个问题

### 价格可能按不同周期展示

同一个套餐可能同时显示月付、季度、半年付和年付价格。不能只看一个数字就判断哪个方案最划算。应先统一换算成月均价格，再考虑是否需要一次性支付更长周期。

### 机房迁移不代表所有线路都一样

官方支持机房迁移，但迁移后 IP、路由和访问表现可能发生变化。购买前要确认目标机房是否对当前套餐开放，不能把“可迁移”理解为可以免费切换到所有机房。

### 备份、快照和自动备份不是同一件事

标准促销 VPS 页面通常列出自动备份和快照，但不同产品的保留周期、恢复方式和限制需要以订单及服务条款为准。重要数据仍应保留独立的异地备份。

### 自主管理需要基本安全配置

购买后至少应该完成这些工作：

1. 禁止 root 直接密码登录，改用 SSH 密钥。
2. 设置防火墙，只开放必要端口。
3. 定期更新系统和服务组件。
4. 为数据库和网站目录设置自动备份。
5. 监控磁盘空间、内存、负载和流量。
6. 为域名、面板和 SSH 开启额外安全保护。
7. 不在公开代码仓库中保存 API 密钥和私钥。
